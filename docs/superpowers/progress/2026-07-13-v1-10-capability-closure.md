# UTA Desktop v1.10.0 能力闭环进度

## 已完成

1. 主聊天和复杂任务接入知识库检索，并保存、显示引用来源。
2. 新增未完成任务恢复中心，支持继续和放弃 checkpoint。
3. API Key 迁移到 macOS 钥匙串，删除本地配置中的明文 Key。
4. Skill 候选支持生成草稿、人工审核、启停和回滚；用户 Skill 写入 `~/.uta/skills`。
5. 新增 15 条中文核心任务评测及桌面入口。
6. RAG 升级为向量与 BM25 混合召回、独立重排和质量基准。

## 验收基线

- 中文核心任务评测：15/15。
- RAG 内置基准：Hit@3 100%，MRR 1.00。
- 版本：Python、HTTP API、macOS 应用统一为 1.10.0。

## 边界

- Skill 必须经过人工审核才能启用，不允许模型自动发布。
- 内置 Skill 不直接修改，用户版本以覆盖方式加载。
- RAG 基准是固定离线样本，用于防止检索排序回退，不等同于真实业务文档评测。
- 多 Agent 协作仍保留给后续 2.0 阶段。
