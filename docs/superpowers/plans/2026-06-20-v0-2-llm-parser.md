# UTA V0.2 LLM Parser 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标:** 完成 `v0.2-llm-parser`：新增统一 `LLMClient` 和 `TaskParser`，让 CLI 主流程可以把用户任务解析成 `summarize` / `data_analysis` / `unknown`，同时保留 v0.1 的 mock loop。

**架构:** `llm/llm_client.py` 只负责 OpenAI-compatible HTTP 调用和 JSON 解析。`core/task_parser.py` 只负责把 LLM JSON 转成 `Task` 并做 Python 兜底校验。`main.py` 负责把 parser 输出写回 `AgentState`，再继续执行原来的最小 loop。

**技术栈:** Python 3.12 标准库 `urllib.request` / `json` / `re` / `pathlib`，pytest，现有 dataclass 模型。
