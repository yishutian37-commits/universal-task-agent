# UTA 长期记忆管理实施记录

## 目标

把长期记忆从只读总览改造成可检查、可纠正、可停用和可删除的管理界面，同时保证旧数据兼容和模型上下文安全。

## 数据约定

- `memory_id` 是更新和删除的唯一定位键。
- 旧记忆缺少 `enabled` 时按启用处理。
- `enabled: false` 的记忆仍保存在本地，但不进入模型上下文。
- 人工编辑写入 `updated_at`，不覆盖原始来源会话和首次/最近出现时间。
- 删除后同步重建长期记忆 profile 缓存。

## 验收

- 可搜索内容、类别、来源会话和记忆 ID。
- 可编辑内容、停用、重新启用和删除。
- 默认列表与模型上下文都排除已停用记忆。
- 可选择显示已停用记忆并恢复启用。
- API、存储层、前端资源和完整回归均有测试覆盖。
