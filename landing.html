任务输入不离开窗口

Loop 过程逐步展开

结果和状态并排可审

v0.6 数据分析链路

从表格文件到可校验报告

桌面端保留学习价值：不仅展示结论，还把字段识别、缺失值、异常值、分类汇总和数字一致性校验显式露出。

FileTool 识别表格路径

支持本地 .csv / .xlsx，把 file_kind 标为 table 交给后续工具。

TableTool 输出结构化统计

字段、行列、缺失值、IQR 异常、分类 Top values 保持为可追踪数据。

ReportTool 生成固定小节

字段说明、基础统计、异常数据、分类汇总、业务解释、后续建议全部保留。

Verifier 做 L1 数字一致性

报告中的行数、列数、缺失值、异常值必须与工具结果完全一致。
